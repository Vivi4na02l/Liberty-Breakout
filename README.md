# Liberty Breakout

An interactive game experience designed to communicate the events of the Carnation Revolution (25th of April, 1974) through gameplay and storytelling.

This project evolved from an experimental [Breakout game](https://github.com/Vivi4na02l/Breakout-game) into a historically-driven interactive experience.

## 🎯 Concept
Liberty Breakout combines short narrative moments with three mini-games to present key ideas and values associated with the Portuguese Revolution of 1974.

The project prioritizes physical interaction as a way to strengthen engagement with the content.

## 🕹️ Interaction Modes
- **Arduino Controller**  
  Custom-built controller designed and implemented by me.  
  Primary interaction method during development.

- **Keyboard Controls**  
  Available as an alternative interaction method.

## 🛠️ Tech Stack
- JavaScript
- p5.js
- Arduino

## 🧠 What I focused on
- Translating historical concepts into game mechanics
- Designing meaningful interaction beyond traditional controls
- Integrating physical input devices with browser-based games
- Structuring short interactive experiences for public exhibition
